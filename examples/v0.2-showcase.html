3. Carousel (轮播交互)

使用原生 CSS Scroll Snap 特性实现的丝滑手势交互分屏组件。

特性一：全原生驱动

没有复杂的 DOM 操作，只需手势或触控板轻轻一划。

特性二：响应式适配

不论是移动端还是桌面端，都能保证中心对齐和整屏滚动。

特性三：优雅的玻璃拟物

继承了默认主题精雕细琢的柔和边框与高级渐变投影体系。

4. Details (智能折叠面板)

原生 <details> 封装，自动携带过渡动画，非常适合存放长篇幅备注或次要内容。

点击查看完整的架构底层变更日志

  1. Parser 层：为保证对 HTML 规范的尊重，采用了 Markdown-it 的原生 Tokenizer，对新增的块级标签执行自定义规则分发。

  2. Validator 层：扩展了超过 20 条新规则，保障图表多系列、双滑块极值、看板子节点等树形结构的严格类型安全。

  3. Renderer 层：全面抛弃 React/Vue 绑定，在核心包中纯拼接标准 HTML DOM，实现 100% Client Agnostic 的极速加载体验。

5. Embed & Math (媒体嵌入与公式)

处理视频、地图或外部挂载应用，以及专业数学公式。

Bilibili / YouTube 嵌入

6. Grid (网格与瀑布流)

v0.2 引入了灵活的多列定义和瀑布流排版能力。

轻量级瀑布流

无需 JS
