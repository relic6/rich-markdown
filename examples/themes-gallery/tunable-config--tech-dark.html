How requests flow

  1. Request → Bucket has token?
  2. Bucket has token? → Allow
  3. Bucket has token? → Refill check
  4. Refill check → Allow
  5. Bucket has token? → Refill check
  6. Refill check → Reject 429

Tradeoffs

Watch the burst window

A wide burst window smooths short spikes but lets sustained overload through longer. If your downstream is fragile, prefer narrow windows even at the cost of more 429s.

Sane starting point

For most APIs, capacity ≈ 4× refill rate, burst window ≈ 10 s. Adjust from there based on observed P99 incident shape.
